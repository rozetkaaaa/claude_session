# Cloudflare-будильник для Claude Session Keeper

Зачем: расписание GitHub ненадёжно (запуски по cron могут не приходить совсем), поэтому момент пинга задаёт Cloudflare Worker.
Он просыпается ровно в момент сброса 5-часового окна, запускает workflow на GitHub, GitHub делает один пинг и сообщает следующее время сброса.
Нагрузка на Cloudflare: около 10-15 вызовов в сутки (бесплатный тариф даёт 100 000).

## Установка
Нужны: Node.js, аккаунт Cloudflare (бесплатный), репозиторий с workflow на GitHub, уже добавленный секрет CLAUDE_CODE_OAUTH_TOKEN.
Дважды щёлкните setup.bat и идите по шагам. Скрипт спросит время сброса из /usage Claude Code (например 19:50).

## Безопасность (что именно защищено)
- Создаётся отдельный Worker со случайным именем (claude-keeper-xxxxxxxxxx). Другие Workers и данные аккаунта не читаются и не меняются.
- Токен GitHub вы вставляете скрыто. Он хранится в Cloudflare как секрет (из панели прочитать нельзя) и имеет право только запускать workflow одного репозитория.
  Он не даёт доступа ни к коду, ни к секретам, ни к другим репозиториям.
- Токен Claude остаётся только в секретах GitHub. В Cloudflare его нет.
- Worker отвечает 404 на любой запрос без правильного пароля; пароль сравнивается за постоянное время; пароль генерируется случайно (256 бит).
- В репозитории нет ни одного токена, пароля или адреса уведомлений.
- В конце установки скрипт выполняет wrangler logout, и на компьютере не остаётся входа в ваш Cloudflare.
- Пароль для управления хранится на вашем компьютере только в зашифрованном виде (шифрование Windows, привязано к вашей учётной записи).

## Управление
keeper-control.bat status | start ЧЧ:ММ | stop | unblock   (файл лежит в папке %USERPROFILE%\.claude-keeper-cf)
Удалить Worker полностью: в панели Cloudflare -> Workers -> claude-keeper-... -> Settings -> Delete.
